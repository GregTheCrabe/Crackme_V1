# Crackme_V1 🦀

Mon tout premier projet développé en **Rust** ! Il s'agit d'un petit défi de cybersécurité (Crackme) conçu pour mettre en pratique les concepts fondamentaux du langage.

## 🚀 Objectif du projet
L'application demande un mot de passe à l'utilisateur. Le but est d'analyser le code source ou le binaire pour comprendre la logique de validation et trouver la clé secrète. 

*(Note : Comme il s'agit d'un projet d'apprentissage, la solution se trouve de manière transparente dans le code source !)*

## 🛠️ Compétences Rust développées
Ce projet m'a permis de prendre en main et de valider les concepts suivants :
* **Gestion des entrées/sorties (I/O) :** Lecture des saisies utilisateur dans le terminal via `std::io`.
* **Manipulation des chaînes :** Nettoyage des espaces et comparaison sécurisée de chaînes (`String` et `&str`).
* **Logique conditionnelle :** Structure de contrôle (`if / else`) pour la validation.
* **Compilation :** Gestion du cycle de vie du code avec `Cargo` et génération d'une build optimisée (`Release`).

## 📦 Comment tester le projet ?
Pour exécuter ce projet localement, vous devez avoir [Rust](https://rust-lang.org) installé sur votre machine.

1. Clonez le dépôt :
   ```bash
   git clone https://github.com/GregTheCrabe/Crackme_V1.git
   ```
2. Accédez au dossier :
   ```bash
   cd Crackme_V1
   ```
3. Lancez l'application :
   ```bash
   cargo run
   ```
